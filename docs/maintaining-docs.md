# 文档写作与验证

[文档首页](README.md)

仓库 README、`docs/` 与各公开包的说明都是面向使用者、集成开发者和维护者的正式文档。文档的目标是让读者形成可以使用、推断和扩展系统的认识。项目首页说明定位与入口，共同概念建立词汇，使用者指南解释实际行为，开发者指南帮助构建应用，架构说明内部关系。参数和字段留在参考页。

## 文档范围

正式文档只描述已实现的功能、可执行的操作、集成契约和明确的限制，按稳定主题命名。版本迁移说明和 Changelog 用于帮助用户升级。

不在正式文档中保留带日期的开发记录、临时设计稿、RFC、选型调研、实施计划、重构日志、单次实验或验收报告，也不保留 UI 原型。已实现且需要用户了解的结论写入对应教程、参考或架构章节；过程讨论放在 issue / PR，设计演进通过 Git 历史查阅。删除过程材料时同步修正导航和引用。

新功能的用法、配置、接入约定与内部机制分别补充到既有指南、参考和架构章节，不新增某个功能的独立设计文件。`architecture.md` 统一维护装配、运行时、执行、上下文与数据的内部机制，使用章节锚点索引。源码目录的 README 用于包的用途、安装、调用或测试说明，不能作为零散设计稿的存放位置。

测试所需的任务输入、业务夹具和运行时 Skill 属于程序资源，保留在相应源码目录。测试使用说明应写明运行条件、入口、产物和判定边界；单次运行结果保存在忽略版本控制的产物目录，不作为功能已实现或已通过的长期文档依据。

## 章节的组织

以稳定主题组织章节，例如会话、工具、知识、装配和事件。开头说明本章对象及其与上一层的关系，正文解释行为、原因和边界，再给例子或进一步阅读。读者应能沿着章节理解一次工作，而不是先记住全部包名和类型。

使用者章节从实际操作写起，解释能观察到什么、怎样继续和结果意味着什么。开发者章节从完整可运行程序推进到扩展与宿主；不要把仓库贡献规范当成应用开发教程。架构章节讲控制流、状态归属和生命周期，源码路径只作为证据与阅读入口。

表格用于比较确实需要对照的选项；流程图用于解释分支、时序和多方关系。它们不能替代正文中的因果解释。FAQ 可以作为查阅补充，不作为整套文档的主结构。

## 行为的归属

| 内容 | 主要位置 |
| --- | --- |
| 框架、发行版、模型、会话、知识的关系 | 基本概念 |
| 安装、任务控制、工具使用、恢复、扫描与协作 | 使用者指南 |
| 扩展实现、配置接入、会话嵌入、协议宿主 | 开发者指南 |
| 装配、运行循环、执行、上下文与事件的内部契约 | 架构 |
| 参数、默认值、环境变量、协议字段 | 参考 |
| 版本变化、升级步骤、兼容边界 | Changelog、迁移文档 |

同一行为由一个主章节解释，其他章节通过链接提供所需深度。例如恢复的操作写在会话指南，事件文件与传输格式的区别写在数据架构；二者不再各复制一份完整教程。版本文档应明确对应版本，当前教程与参考始终以当前实现为准。

## 示例与事实

命令需要写明前置配置、工作目录、发行版和预期观察。示例中的目标与密钥使用本地或占位值。Go 教程优先链接仓库里的完整程序，正文只摘取解释所需的部分。

行为以当前代码和实际验证为准。声明了 flag、接口或配置字段，并不能证明对应执行路径已经接通；设计目标也不能写成现状。涉及迁移时明确当前入口、已实现部分和限制，发布版本的读者通过 Git tag 查看相应内容。

## 验证

在仓库根目录执行：

```sh
node docs/check-links.mjs
go run ./examples/custom
go run ./examples/session
go test ./core/resource ./core/extension ./core/registry ./core/tool ./examples/custom ./examples/session
```

链接检查覆盖根 README、docs 下的手写 Markdown，以及 audit、harness、ACP 示例和 Web 前端测试的正式说明，检查普通行内本地链接、标题锚点及代码围栏。本地生成的 API 字段文档不作为扫描源，代码块里的示意链接不检查；它不是完整的 Markdown/HTML 解析器，也不验证外部 URL 可达性。

两个例子分别验证工具注册调用和会话历史连续性。它们不调用远程模型，不验证供应商流式接口、Web 部署或实际目标扫描。修改相关集成行为时，需要补充对应验证并报告范围，不能用示例通过代替全部端到端验证。

合并或删除页面时同步更新导航、站内链接和源码目录中的引用，保留的正式说明必须能从主指南找到。修改行为时同时更新主要解释页和参数参考，提交说明包含具体变化、验证结果及尚未验证的边界。
